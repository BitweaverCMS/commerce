# Commerce documentation index

One line per document. Open a file only when the task is that concern.

- [orders.md](orders.md) — orders, status history, payment-adjustment currency, the product log, order-list search, customer purchase options, and the invoice payment panel. Open for an order, the invoice, the order list, or a customer purchase option.
- [dropship.md](dropship.md) — CSV upload, Process vs checkout, `active_cart`, payment and shipping from the row, and current drop-ship gaps. Open for `/bookstore/dropship`.
- [product-order.md](product-order.md) — user-scoped center list order and `products_sort_order`. Open when a profile product grid is in the wrong order.
- [taxes.md](taxes.md) — sales-tax report, filing cycle, recorded tax payments, and the report page layout. Open for a tax report or a tax payment.
- [architecture.md](architecture.md) — initialization, components, and request flow. Open for how commerce starts.
- [source-reference.md](source-reference.md) — files, classes, controllers, schema, and templates. Open to find a source file.
- [development.md](development.md) — change rules, admin layout, form actions, and list flags. Open before editing commerce behavior.
- [security.md](security.md) — trust boundaries and direct-HTTP denial. Open for an access question.
- [commerce-lifecycle.md](commerce-lifecycle.md) — cart, checkout, the product order-deadline hook, plugins, and shipping boxes. Open for checkout or a plugin.
